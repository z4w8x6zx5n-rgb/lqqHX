# 刘启全化学冲刺网页

这是一个可直接部署到 GitHub Pages 的高中化学冲刺静态网站。

## 文件

- `index.html`：网页入口
- `style.css`：页面样式
- `script.js`：知识点数据、首页列表和详情切换逻辑

## GitHub Pages 使用方法

1. 在 GitHub 新建仓库。
2. 上传这三个网页文件。
3. 进入仓库 `Settings` -> `Pages`。
4. `Source` 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub 生成访问链接。

继续扩充内容时，主要编辑 `script.js` 中的 `topics` 数组即可。
